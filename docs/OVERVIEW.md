# Documentation Overview

This folder contains the supporting product documentation for the Smart Attendance System.

## Included Documentation
- `API_REFERENCE.md` — API endpoints and request/response details.
- `DATABASE.md` — Database schema, migrations, and data model notes.
- `PROJECT_STRUCTURE.md` — Repository organization and component layout.
- `RBAC.md` — Role-based access control model.
- `TEST_REPORT.md` — Testing and validation notes.

## Archive
- `archive/` — Historical reports, audit artifacts, and duplicate documentation moved out of the release root.

## Usage
- Use the root-level `README.md` for quick onboarding.
- Use `ARCHITECTURE.md` and `DEPLOYMENT_GUIDE.md` for release planning.
- Use `SECURITY.md` for security policies and controls.
